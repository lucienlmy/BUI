# Changelog

## 0.1.0

- Highlighting for `rsx!` / `view!` bodies inside Rust: tags, components, attributes, variant prefixes, class strings, `{expr}` embeds, text strings.
- Tailwind class highlighting in `tw!("...")`.
- Snippets for `rsx!`, `#[component]` and common elements.
- Tailwind class-name completion inside `class="..."` in rsx blocks.
